Проект 6 спринта
В проекте были созданы автотесты для сайта по заказу самокатов
Тестовые сценарии:

Выпадающий список в разделе «Вопросы о важном».

Проверки кнопок «Заказать».

Заполнение формы заказа.

Проверка, что появляется всплывающее окно с сообщением об успешном создании заказа.

Проверка: если нажать на логотип «Самоката», попадёшь на главную страницу «Самоката».

Проверить: если нажать на логотип Яндекса, в новом окне через редирект откроется главная страница Дзена.

Тесты написаны с разными данными, которые автоматически генерируются при помощи fakerов.

Необходимые локаторы отсортированы, и по категориям расположены в директории locators.
Создан отдельный пакет для каждой страницы с Page Object.
Все тесты лежат в директории test, и отсортированы по функциональности.
Для теста на содержимое вкладок с вопросами и ответами написан параметризированный тест.
Создан отчёт в Allure, и приложен к проекту.
